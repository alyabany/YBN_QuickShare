# 🚀 YBN QuickShare

**YBN QuickShare** هي أداة خفيفة وسريعة لمشاركة ورفع الملفات محلياً عبر شبكة الـ Wi-Fi أو LAN، مصممة بلغة **Python** وباستخدام إطار العمل **FastAPI**.

تتيح لك الأداة مشاركة الملفات والمجلدات بين مختلف الأجهزة (واتساب، هواتف، حواسيب) داخل نفس الشبكة بدون الحاجة للاتصال بالإنترنت، مع واجهة مستخدم مظلمة (Dark Mode) وعصرية تدعم اللغة العربية بالكامل.

---

## ✨ المميزات الرئيسية (Features)

* ⚡ **مشاركة سريعة وبدون إنترنت:** نقل الملفات والمجلدات عبر الشبكة المحلية بالسرعة القصوى للراوتر.
* 📤 **رفع وتنزيل الملفات:** إمكانية رفع الملفات مباشرة من أي جهاز مع تصفح المجلدات الفرعية وتنزلها بسهولة.
* 🌐 **اكتشاف IP تلقائي:** يتعرف التطبيق تلقائياً على عنوان الـ IP المحلي للشبكة لتسهيل الوصول إليه من الأجهزة الأخرى.
* 🎨 **واجهة عصرية (Dark Theme):** تصميم متجاوب وأنيق ومريح للعين مع دعم كامل للغة العربية والاتجاه من اليمين لليوم (RTL).
* 📦 **تجميع ذاتي ومستقل:** يعمل كملف تنفيذي مفرط (`.exe`) بدون الحاجة لتثبيت Python أو أية مكتبات خارجية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** Python, FastAPI, Uvicorn
* **Frontend:** HTML5, CSS3 (Modern Flexbox Architecture)
* **Packaging:** PyInstaller

---

## 🚀 طريقة التشغيل (How to Run)

### 1. تشغيل الملف التنفيذي المباشر (Executable):
1. قم بتشغيل `main.exe`.
2. سيظهر لك رابط الوصول في نافذة الـ Terminal مثل:
Access the app at: http://192.168.1.X:8050
